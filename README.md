# english-study

33년째 제자리인 영어를 **진단 → 처방 → 훈련 → 재측정** 순서로 고치는 프로젝트.

막연히 "영어를 못한다"가 아니라 어디가 막혔는지 숫자로 찾고, 그 약점만 겨냥해서 4주 단위로 훈련한 다음, 같은 진단으로 변화를 확인합니다.

## 진행 순서

1. **진단** (약 30분) — `diagnostic/english-diagnostic.html`
   어휘량, 즉석 영작, 받아쓰기, 읽기 속도·이해도, 5분 작문, 학습 배경을 측정합니다. 결과는 Artifact 저장소에 기록되어 Claude가 직접 읽고 채점합니다.
2. **분석** — `docs/diagnosis.md` (진단 후 작성)
   자동 채점 결과와 실제 답안(영작 문장, 받아쓰기, 작문)을 함께 보고 핵심 약점 두 가지를 고릅니다.
3. **4주 처방** — `docs/plan.md` (진단 후 작성)
   하루 가용 시간에 맞춘 구체적인 루틴.
4. **기록** — `log/`
   매일 한 일을 짧게 남깁니다. 작문·녹음 교정도 여기에 쌓습니다.
5. **재진단** — 4주마다 같은 진단을 다시 해서 수치 비교.

## 진단 도구에 대해

- `diagnostic/english-diagnostic.html`은 claude.ai Artifact로 게시되는 페이지의 소스입니다 (게시할 때 `<html>`/`<head>` 골격이 자동으로 붙습니다).
- 듣기 파트는 브라우저 음성 합성(Web Speech API)을 씁니다. 일부 안드로이드 앱 내부 화면에서는 소리가 나지 않을 수 있습니다.
- 어휘 문항은 빈도 순위 구간(1–1천 … 1.2–2만)별 8개 단어와 가짜 단어 16개로 구성됩니다. 가짜 단어를 안다고 고른 비율만큼 점수를 보정합니다.
